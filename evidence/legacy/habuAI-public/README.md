# Legacy Habu AI GPX audit provenance

This directory preserves audit metadata copied from the earlier public
`haji84/habuAI` repository before raw-byte migration into the private
canonical repository.

The SHA-256 values in `v2_actual_gpx_13night_qc.csv` are the identity keys for
the 13 verified ACTUAL_GPX nights. Filenames are descriptive only and must not
be used as the identity check.

The historical bundle remains a source artifact until each original GPX is
migrated and independently matched by raw SHA-256. Registration of this
metadata does not itself claim that the old raw bytes are already present in
the private repository.
