## Design and scope

Keep the existing evidence audit, LearningSnapshot v1, prospective inputs and
parent orchestrator. Add a small, read-only development-cycle contract that
binds their exact implementation/schema bytes to one versioned shared policy.
It certifies interface consistency only; it cannot admit observations, read
confirmation outcomes, fit a model, issue P0 or activate a Champion.

Alternatives considered: replacing LearningSnapshot would duplicate reviewed
work; adopting PR #46 unchanged would admit PASSAGE noncaptures despite current
AGENTS. The chosen additive contract lets the existing PR be repaired without
changing historical v1 behavior or inventing a new scientific pipeline.

The shared policy freezes owner-capture binary target semantics, UNKNOWN=null,
independent scoped active-search plus complete outcome proof for a noncapture,
individual/event separation, EPSG:32652 100m cells and 600s windows, 07:00 JST,
strict ex-ante availability, full outside-universe individual denominator,
Stage1 Top10/0.90, sealed confirmation restrictions and existing budgets.
Actual folds and cohort artifacts remain unallocated: no eligible dataset or
untouched confirmation has been proved. V owns their later hash-bound allocation.

The pure time API derives operational night and the effective training boundary
`min(fit cutoff, forecast cutoff, evaluated-night 07:00 JST)`. Availability is the
maximum of source receipt, derivation, audit and materialization readiness;
equality at the boundary is rejected. The API does not infer historical valid
time, labels or data authenticity.

Cycle manifests bind fixed role/path references with SHA-256, a base Git SHA and
declared freeze time. Bounded reads reject absent/tampered references, traversal,
absolute/Windows paths, symlinks and unexpected fields. The fixed role list
includes the validator, schema, policy, existing evidence/learning/evaluation/
candidate implementations, and dependency pins. Returned status is always
CONTRACT_VALIDATED with science NOT_VALIDATED and production authorization false.
The manifest's declared timestamp/hash is not a trusted pre-reveal receipt.
The closure is conservatively every Python file under src/ and scripts/, every
JSON schema, and the two existing dependency profiles. Its membership is derived
by the validator rather than chosen by a caller. The machine policy records
folds=UNALLOCATED and confirmation=UNSELECTED; all scientific execution is blocked.
Required readiness timestamps cannot be omitted. This first slice contains no
outcome reference and never reads or hashes sealed outcome files.

Windows checkout conversion currently changes historical TXT/GPX bytes. Audits
must use exact Git blob bytes in a separate derived snapshot, leaving checked-out
Raw and ORIGINAL files untouched. Source hashes bind bytes, not normalized text.

## Acceptance and review focus

Reject cutoff equality/backdating, same-night training, UNKNOWN-as-zero,
PASSAGE-as-search, denominator narrowing, missing code closure, changed bytes,
unbounded input and confirmation content reads. Fixture successes are software
evidence only. Preserve historical M0–M3, all Raw/ORIGINAL bytes and production
authority. Current Windows full-suite baseline: 308 tests, 122 errors, with
Linux-only fcntl, cp932 decoding and CRLF/source-hash failures; no changes have
been made to bypass those checks. Ubuntu Actions is the existing full-suite
verification environment; WSL is not installed and is not added by this slice.
