## Research computations and real ablation

Research reads development labels only and generates questions from actual misses, high uncertainty, calibration error and spatial/temporal residual patterns. Include the requested covariate catalog with present/missing provenance so weather, wind, tides, moon, terrain, roads, season/time, past activity, effort, transition/neighbor/large-individual/geographic-diversity features receive specific data requirements. Do not claim each is implemented simply because arbitrary numeric columns are accepted.

Implement three numerical analyses: (1) univariate regularized logistic effect/held-out Brier for each preregistered eligible feature, (2) adjusted logistic with frozen controls plus that feature/group, (3) preregistered interactions added to their main effects and controls. Reuse train-only folds/transforms. Report feature scales, effective observed units/nights, class balance, held-out change, coefficient signs and uncertainty/coverage. These are observational associations, not causal effects. Fit diagnostics and failures must be explicit. No naive independent-row p-values for autocorrelated trajectory samples.

True model-feature ablation retrains the selected feature-aware recipe on exactly the same training rows after removing a whole preregistered group, including interactions that depend on that group, then evaluates identical held-out units. Refit remaining transformations as training-defined; do not merely zero a feature at inference and call it retraining. Report full-versus-ablated paired per-night Brier, rank/recall changes and fit evidence. Group choices are fixed before confirmation. Development ablations support feature selection; confirmation ablations, if preregistered, are diagnostic and cannot be used to choose a new winner on those labels.

These diagnostic fits do not count as additional promotion candidates only if they are structurally ineligible for selection/promotion and clearly recorded as diagnostics. They still consume compute and are capped. If an ablated/interacted recipe is selected for possible promotion, it is one of the three registered candidates; it cannot enter as an invisible fourth. Detect redundant/harmful groups by out-of-fold ablation evidence, not coefficient magnitude alone. Coefficient magnitude after scaling is an association description, not universal importance.
